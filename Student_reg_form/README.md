# 🎓 Student Registration Form  
**Department of Computer Science**

## 📁 Files Included
- **index.html** — Main HTML file containing the registration form structure.  
- **styles.css** — External stylesheet for layout, responsiveness, and design.  
- **README.md** — Project documentation and usage instructions.  

---

## 🚀 How to Run
1. Download or clone all project files into a single folder.  
2. Open `index.html` in any modern web browser (Chrome, Firefox, Edge, etc.).  
3. The form will display with a **two-column layout** on desktop and **stacked layout** on mobile.  
4. All inputs are built with **HTML5 and CSS3 only**, no JavaScript required.  
5. To enable built-in browser validation, remove the `novalidate` attribute from the `<form>` tag in `index.html`.

---

## 🧩 Features
- Fully responsive using **Flexbox** and **CSS media queries**.  
- Semantic HTML structure with proper `label`, `fieldset`, `legend`, and `aria-*` usage.  
- Accessibility-focused design with clear labels and placeholders.  
- CSS variables used for easy color and spacing customization.  
- Includes modern form controls:
  - `input[type=text|email|tel|date|password|file|radio|checkbox]`
  - `select`, `optgroup`, `textarea`, and `datalist`  
- Custom focus states and smooth CSS transitions.
